# H₂ 势能实验室 v5.1 · 能量与力

[在线演示](https://hang-999.github.io/h2-potential-lab/) · [源码仓库](https://github.com/hang-999/h2-potential-lab)

GitHub Pages 提供静态网站托管；GitHub Actions 执行测试和构建。交互训练由访问者浏览器的本地 CPU 执行，训练数据和模型参数保存在当前页面内存中。

双击 `index.html`，在桌面 Edge / Chrome 中离线使用。该文件内嵌全部 CSS、JavaScript、SVG 和 Web Worker，不需要 Node.js、服务器、账号、GPU 或网络。所有真实训练在接收者电脑的 CPU 中完成。

## 开始使用

默认是 `1→32→32→1`、tanh、Adam、80 样本（64 训练 / 16 验证）、Batch Size=8、学习率 0.01、500 Epoch。点击“开始训练”，或用“+1 Step”执行一次真实小批量更新。

编辑网络、训练或数据参数会暂停训练，保留当前结果。“应用并重新初始化”统一重建模型、数据、优化器和计数；“撤销编辑”恢复已应用设置，“恢复默认”只填写待应用设置。尚未提交的讲解会被取消。探针、显示范围、标尺及播放速度保留模型。

## 页面与操作入口

本版在既有真实训练上增加解析力推理、可选联合损失、外推预设和冻结对照。训练按钮和 Step、Epoch、训练/验证误差放在顶部持续可见的操作栏，滚动页面时仍可暂停或单步更新。演示速度和阶段动画速度在顶部“演示速度”中设置。完整计算约定见 [能量与力说明](../ENERGY_FORCE.md)。

- **拟合与误差**：查看 Morse 参考、训练/验证点、实时预测、残差、键长探针和真实损失历史。“导出 CSV”在主图右上方。
- **网络与计算**：查看网络或权重矩阵，选择节点/连线，并进入“逐步讲解”。小型拟合图与数值解释放在计算区旁边；较窄屏幕按可用空间排列。
- **样本与批次**：查看当前批次、已处理样本和验证点。点击样本会切到拟合视图并移动键长探针。

三个工作视图仅切换显示，不重新初始化模型，也不额外更新参数。模型参数位于独立滚动的参数栏，窄屏可折叠；顶部“参数设置”可返回并展开参数栏，点击参数栏标题可收起。“应用并重新初始化”和“撤销编辑”等操作放在参数区底部，避免与长参数列表一起滚出可视区域。参数中的“高级模型与采样设置”默认折叠。

“拟合与误差”顶部的实验引导默认折叠，需要时展开选择一次更新、网络容量、Batch Size 或激活函数实验。引导只预填草稿；仍需点击“应用并重新初始化”。

网络图每个显示列最多排列 16 个神经元；例如真实的 32 神经元隐藏层分成两列显示，**这两列仍属于同一个隐藏层，不是新增网络层**。每个节点保留原编号和真实连接。可使用“图缩放”切换 80%、100%、125%、150%；超出区域的图形在图内滚动，缩放不改变模型或训练计数。大矩阵也在自己的显示区域内滚动。

选中对象的计算详情分为“数值与公式”“激活函数”“逐项计算”三个标签。查看长输入项表或梯度贡献时，不必把整个解释面板全部展开。

## 可调参数

- 隐藏层 0–4 层，每层独立 1–64 个神经元；每层选择 tanh / ReLU / Leaky ReLU / sigmoid / Softplus。输入、输出固定各一个，输出线性。0 隐藏层是线性基线。
- 训练目标为仅能量（默认）或能量＋力；力权重0–10，联合默认1。联合模式允许线性模型与平滑激活层。Softplus 的 β=1；ReLU 系列保留能量训练与导数曲线观察。
- 自动匹配初始化、Xavier 均匀、He 均匀、全零。自动模式在 tanh/sigmoid/Softplus 层用 Xavier，在 ReLU 系列层用 He；线性输出用 Xavier。Leaky ReLU 负斜率固定 0.01。
- 随机种子为 0–4294967295。初始化、数据生成/划分、Epoch 重排采用独立随机流。改变网络形状不改变同种子的采样与批次顺序。
- Adam、SGD、Momentum SGD；学习率 0.0001–0.1；恒定或余弦衰减；终值比为 0.01–1。Momentum 系数 0–0.99；Adam β₁ 0–0.99、β₂ 0.9–0.9999，ε=1e-8。
- 样本数 20–400，5 的倍数；验证比例 10%–40%，5% 步长，四舍五入计算验证点数；间隔划分或固定种子随机划分。Batch Size 从 1 到当前训练点数；Epoch 从 1 到 2000。尾批次保留，每轮实际重排。
- 等距、分层随机、势阱加密采样；覆盖区间位于 0.30–3.00 Å，宽度至少 0.20 Å。非等距采样保留端点。势阱加密约 60% 内部样本位于覆盖区间与 0.45–1.25 Å 的交集，其余覆盖整个区间；无交集时明确提示退回等距。
- 训练速度上限 1–100 次更新/秒；动画速度 0.5× / 1× / 2×。实际速度取决于 CPU 和网络规模。

配置可导入/导出 JSON（`schema: h2-lab-config, version: 2`），兼容旧v1的仅能量设置。配置不包含训练权重或进度，导入先进入待应用状态。CSV 导出所有采样点的键长、能量参考/预测/残差、划分、力参考/预测/残差和模型 Step。

## 看见计算过程

在“网络与计算”视图点击“逐步讲解”，连续训练暂停，准备下一批数据。阶段 1 前向、阶段 2 损失、阶段 3 反向均只展示冻结的真实计算；阶段 4 提交一次更新，Step 才加一。回放与重播不训练，提交前取消不会改变权重、优化器、随机状态或计数。切到其他工作视图再返回，可继续查看当前讲解。

- 右侧小图同时展示参考曲线、更新前拟合和提交后的拟合，同步展示真实批次损失及训练/验证 RMSE。局部误差可以真实变大。
- 点击节点查看加权和、激活、偏置及样本 δ；点击连线或矩阵单元格查看平均梯度、参数旧值/新值及 Δw。
- Adam 展开 m、v、偏差修正及更新公式；Momentum 显示实际动量，SGD 显示 −ηg。
- 激活函数图展示 f(z)、f′(z) 和当前切线；神经元响应图展示 aⱼ(r)，两者含义不同。
- 最后隐藏层可看能量贡献 cⱼ(r)=σEwⱼaⱼ(r)，加上其他项及 μE+σEb 重建输出。它是数学分解，不代表独立物理作用。
- 矩阵按“输出行 × 输入列”排列，与网络共用权重/梯度/更新量及标尺。超过 2000 条连接默认矩阵，只绘制局部网络；淡色示意路径不是完整影响分解。
- 标尺可以锁定或自动，显示截断项数。主图默认固定参考纵轴，超出范围的预测有边缘提示；切换自动范围可查看全部预测。显示裁剪不会修改模型或误差。
- 数值梯度检查暂停训练但不修改模型、优化器或 Step。ReLU 折点处不可微，因此可能出现差分不一致，界面明确说明。

界面为保持响应，默认实时训练最多发布 10 次一致快照/秒，超过 2000 条连接时最多 2 次/秒；暂停、单步和讲解立即评估。每张图均标明对应模型 Step。历史点均来自真实评估，没有模拟下降曲线。大网络 CPU 演示会更慢，100 次/秒只是上限。

## H₂ 参考数据与数值约定

Morse 经验势：

`E(r) = 4.748 [1 − exp(−1.944(r − 0.7417))]² − 4.748`

r 单位 Å，E 单位 eV，解离极限为零，最低点为 −4.748 eV。参数参考 [LBNL 资料](https://escholarship.org/content/qt6wk7d53s/qt6wk7d53s.pdf)（印刷页 −66− 附近）。这是经验势教学参考，不是高精度量子化学数据集。完整参考曲线固定 601 点。

输入和输出的标准化统计只使用训练集。仅能量项的样本 δ 已包含1/B，其 a×δ 求和等于该项平均参数梯度。联合目标还包含输入导数路径的混合导数，界面分别列出能量梯度、加权力梯度与总梯度。总目标无量纲；能量 MSE/RMSE 使用 eV²/eV，力 MSE/RMSE 使用 (eV/Å)²/eV/Å。分区误差基于完整参考网格，单独标注，不冒充验证指标。

全零初始化、过窄网络或不合适的训练参数可能产生很差的拟合。遇到非有限更新会停止并恢复更新前的有效数值状态，保留结果供查看；调整设置后重新应用。不同配置不保证收敛。

## 编辑、构建与测试

- `engine.js`：配置验证、Morse、采样、动态 MLP、归一化、反向传播、优化器、事务、快照及梯度检查。
- `worker.js`：后台调度、实时限频和消息协议。
- `settings.js`：配置草稿、应用/撤销、导入/导出。
- `charts.js`：原生 SVG 曲线与持久矩阵单元格。
- `network-panel.js`：动态网络、动画、讲解、解释与贡献图。
- `app.js`：工作视图、页面、探针、误差、CSV、实验引导及 Worker 生命周期。
- `page.html`、`ui.css`：页面结构与统一的响应式样式。

开发需要 Node.js，无需安装 npm 依赖；网页使用不需要任何安装。在源码文件夹执行：

```
node build.cjs
node test-engine.cjs
node test-worker.cjs
node test-robustness.cjs
node test-forces.cjs
```

`build.cjs` 会生成同目录的独立 `index.html`。数值测试覆盖所有激活、三种优化器、动态层数、事务等价、数据随机流、默认收敛、最大网络及故障回滚。

## 自动测试与发布

推送到 `main` 时，GitHub Actions 依次执行 JavaScript 语法检查、整站 `npm test`（包含本目录四组数值/状态测试）及单文件构建，验证生成的网页与提交内容一致后，将网页发布到 GitHub Pages。Pull Request 只运行检查，不发布网站。

修改 `page.html`、`ui.css` 或 JavaScript 后，先运行 `node build.cjs`，再将源码和新生成的 `index.html` 一起提交。无需安装 npm 依赖。Pages 部署产物仅含网页，不包含测试脚本和文档。
