# Numerical conventions and verification

All calculations use JavaScript binary64 numbers. New method chapters implement reduced operators, not pretrained interatomic potentials. No backend, Python or machine-learning package is required to run the site.

## Geometry and ACSF

Coordinates are Å. Smooth cutoff is `fc(r)=0.5[cos(πr/rc)+1]` for `r<rc`, otherwise zero. Coincident and near-coincident atoms below 0.15 Å are rejected to avoid undefined directions. Species are stratified H/C/O, and features exclude the central atom.

G2 uses `exp[-η(r−Rs)²]fc(r)`. G4 uses the standard ordered `j≠k` sum with prefactor `2^(1−ζ)`, all three distance cutoffs, and `exp[-η(rij²+rik²+rjk²)]`. For efficient display the engine stores one unordered pair with twice its contribution; clicking a pair therefore represents both orders.

The four-hidden-unit BPNN illustration selects an element-specific matrix initialized using seed 42. Input weight scale, bias scale and output coefficients are editable controls. Its scalar output is dimensionless and untrained.

## SOAP

The finite local Gaussian density is `ρZ(r)=Σj:Zj=Z fc(rj) exp[-|r−rj|²/(2σ²)]`, excluding the center. The projection integral is over the radius `0≤r≤rc`. Real spherical harmonics satisfy `∫Ylm²dΩ=1`; the m order is `−l…l`, with l=1 represented by proportional `(y,z,x)` components. Radial primitives `(1−r/rc)^(n+3)` are orthonormalized with measure `r²dr`.

The engine computes the angular Gaussian projection analytically with modified spherical Bessel functions, then uses 96-node Gauss–Legendre radial quadrature. A scaled Bessel representation avoids overflow for narrow Gaussians. The power spectrum is `pZZ'nn'l=π√[8/(2l+1)]Σm cZnlm cZ'n'lm`. All species/radial cross terms are retained, including their symmetric counterparts. The displayed kernel is the normalized power-vector dot product squared, with zero assigned for a numerically zero norm. This is a documented finite-basis teaching convention, not bit-for-bit compatibility with DScribe's default GTO basis or a GAP prediction.

## Tensors and messages

Moments use weights `wj=fc(rj)exp(−rj²/2)`, unit vectors `uj`, and `s=Σw`, `v=Σwu`, `Q=Σw(uuᵀ−I/3)`. Linear readout uses `[s,v·v,trQ²,trQ³]`; these are genuine rotation invariants but not a complete ACE/MTP basis.

The vector tensor product is decomposed into dot product (0e), cross product (1e, axial) and symmetric traceless part (2e). The underlying input vectors have type 1o. Under improper rotations, the axial vector transforms as `det(R)R a`, not as a polar vector.

Messages combine scalar channels, radial filters, optional angle invariants, and—in the vector variant—vectors using dot products and scalar gates. Embedding/filter/readout coefficients are initialized with Mulberry32 seed 42. Every message and node state is stored by round. The four editable weights change the deterministic teaching computation; no optimizer runs in these chapters.

Correlation demonstrations use `s`, `v·v`, and `vᵀQv` at orders 1, 2 and 3. The full expansion includes repeated neighbor indices. These are selected actual invariant contractions, not a complete MACE architecture or a guaranteed exact body-order label after network composition.

## Energy and forces

For symmetry checks, a constructed smooth pair-plus-angle energy is used:

`E = 0.3 Σi<j fc(rij)(rij−1.2)² + 0.12 ΣiΣj<k fc(rij)fc(rik)(cosθjik+1/3)²`.

Energy is eV with lengths in Å (the pair coefficient has units eV/Å²); the angular coefficient is eV. Forces are analytic `−∇E`, in eV/Å. This is not an H₂O or quantum chemistry reference surface. Latent vectors from the neural illustrations are separately labeled dimensionless features.

## Independent fixtures

`fixtures/reference.json` is generated by `generate-reference.py` using NumPy. SOAP is integrated directly over a three-dimensional spherical grid, without the engine's Bessel projection. Radial basis normalization uses an analytic Gram matrix and Cholesky, independently of the engine's numerical Gram–Schmidt. Two grid resolutions (128×64×128 and 160×80×160) agree to less than 2×10⁻¹⁵ in power terms. ACSF uses an explicit ordered double sum; forces use central energy differences. Stored fixtures allow Node-only tests and reproducible CI without Python.

Run `node test-operators.cjs` to verify fixtures, every geometry preset, rotations/reflections, translation/permutation, multiple network sizes, empty neighborhoods, cutoff continuity, parameter rejection, replay determinism and quadrature convergence. Latest observed results: maximum symmetry residual 6.61×10⁻¹⁶, maximum force finite-difference discrepancy 3.22×10⁻¹¹ eV/Å, SOAP power comparison error 3.13×10⁻¹⁴ using the documented scale-normalized norm. The relative-error denominator is `max(1, ||a||, ||b||)`.
